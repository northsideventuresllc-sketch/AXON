Use "Northside" in standard title case; NORTHSIDE all-caps only in intentional all-caps design contexts. The operator is JB (Jonny), never "Jonathan". The old "NORTHSiDE exact casing" rule is dead — retired by JB 2026-08-25, Decision #1389 — never reinstate it.

Why: this exact dead rule has been mistakenly reinstated multiple times across repos.
