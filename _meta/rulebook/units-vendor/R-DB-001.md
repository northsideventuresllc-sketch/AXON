Never apply a database migration, DDL statement, or new `pg_cron` job yourself. Write it as a `.sql` file in the PR, clearly marked "NEEDS JB APPROVAL — do not apply". Small, additive data-row writes to NI-Brain (Decisions/Learnings/Context, close-out rows) are fine on their own; schema changes are not.

Why: schema/cron changes are effectively irreversible in a shared live database.
